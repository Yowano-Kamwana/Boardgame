# Rootbound — image prompts for 3D model generation

Paste one prompt per image into ChatGPT (or another image generator). Each asks for a single
full-body figure on a plain background, which is what image-to-3D tools such as Tripo work best
with. Attach the matching reference image from this folder where noted.

Shared style line (already included in each prompt):
> Painterly storybook fantasy, matching the Rootbound board game art: warm lantern light, mossy
> textures, soft rim lighting. Single character, full body, front three-quarter view, standing on
> a plain light-grey background, no scenery, no text, no frame.

---
